## Repository Consolidation

Going forward, the .NET SDK team is using the [dotnet/sdk](https://github.com/dotnet/sdk) repository for further development and to respond to issues formerly in this repository.

For more information about the .NET Template Engine, see the [Template Engine documentation](https://github.com/dotnet/sdk/tree/main/src/Cli/Microsoft.TemplateEngine.Cli) in that repository.
